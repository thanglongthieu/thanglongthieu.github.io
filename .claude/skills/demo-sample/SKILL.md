# Demo Sample Skill

A minimal example of a custom skill.

## Instructions

1. Greet the user and say this response came from the `demo-sample` skill.
2. Briefly explain the structure of a skill:
   - A folder named after the skill, containing `SKILL.md`.
   - YAML frontmatter with `name` and `description` (the description tells Claude when to use it).
   - Markdown instructions in the body.
3. Offer to turn the user's own workflow into a skill.

## Example

User: "Show me a skill demo"
Response: "Hi! This reply is powered by the demo-sample skill. A skill is a folder with a SKILL.md file..."
